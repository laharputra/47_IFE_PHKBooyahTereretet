Prediksi Kejadian Hujan Esok Hari Berdasarkan Parameter Meteorologi Menggunakan Naive Bayes dan Random Forest

Proyek Data Science — UPN "Veteran" Yogyakarta

Tahun Akademik 2026/2027

1. Deskripsi Proyek

Proyek ini bertujuan untuk memprediksi apakah akan terjadi hujan pada hari berikutnya berdasarkan parameter meteorologi, seperti suhu udara, kelembapan, tekanan udara, kecepatan angin, dan curah hujan.

Penelitian menggunakan pendekatan Supervised Learning dengan metode Gaussian Naive Bayes dan Random Forest untuk melakukan klasifikasi biner.

2. Dataset

Dataset yang digunakan adalah Rain in Australia, yang tersedia melalui Kaggle.

Sumber: Rain in Australia — Kaggle

Nama file: weatherAUS.csv

Jumlah data: 145.460 baris

Jumlah kolom: 23

Jumlah lokasi: 49

Target prediksi: RainTomorrow

Kategori target: Yes dan No

Dataset memuat data pengamatan cuaca historis Australia yang bersumber dari Australian Bureau of Meteorology.
